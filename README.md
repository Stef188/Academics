## Projects


Auto-Focus Lens System | MATLAB, Simulink, System Dynamics 2025 – 2026

• Modelled and Simulated an auto-focus lens system based on a Rack and Pinion Mechanism. Two versions were created: a PD
and full state feedback system; optimised with high tuning and Ackermann’s Formula.


Gesture Recognition System | Python, MediaPipe, OpenCV, Raspberry Pi 5 2025 – 2026

• Developed a machine learning gesture control system on Raspberry Pi 5 using MediaPipe hand detection.
• Implemented real-time gesture recognition for UI interaction and device control.


PID Controlled Robot | C/C++, Arduino, MATLAB Simulation 2024

• Designed and implemented a PID control system for an autonomous mobile robot based on object tracking.
• Integrated ultrasonic sensors for obstacle detection and autonomous navigation.


PCB Design – 0–5V Voltmeter | EasyEDA, SPICE, EagleCAD 2024

• Designed and simulated an analog voltmeter circuit with 0–5V measurement range using SPICE simulation.


CAD Design – PC Mouse Box | SolidWorks, Onshape, FreeCAD 2024

• Designed and manufactured a parametric PC mouse storage box in CAD, including lid and internal supports, optimized for 3D
printing tolerances
